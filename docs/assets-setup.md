# アセット（立ち絵など）の導入方法

本リポジトリでは、著作権的な配慮から、キャラクターの立ち絵画像や生成された音声・動画ファイルなどのアセットをGitHubリポジトリには含めていません（`.gitignore` によって除外されています）。
ローカルで本ツールを使用する際は、以下の手順でアセットを配置してご利用ください。

## アセットの配置場所

アセットファイルは、リポジトリ直下の `workspace/assets/` ディレクトリ内に配置します。このディレクトリはGitの管理対象外となっているため、誤って公開されることはありません。

**配置例:**
```text
workspace/
└── assets/
    ├── characters/
    │   └── (キャラクターのPNG画像など)
    └── zundamon/
        └── (ずんだもんの立ち絵画像など)
```

## ずんだもん立ち絵のクレジット

本プロジェクトのローカル検証・開発等で使用している「ずんだもん」の立ち絵は、以下の作者様が公開されている素材を利用しています。
同様の素材を利用する場合は、配布元の利用規約に従ってダウンロードし、上記のディレクトリに配置してください。

- **素材元:** [【素材】ずんだもん立ち絵【フリー】 - pixiv](https://www.pixiv.net/artworks/92641351)
- **作者:** 坂本アヒル 様
